# 清晨的咖啡店

到一座陌生的城市，我总爱赶在街道苏醒之前，去找一家清晨的咖啡店。

那时天光还淡，卷帘门刚刚拉起一半。店主一边擦着木桌，一边和熟客低声道早。磨豆机轰隆一声，整间屋子忽然就有了温度——焦糖与坚果的气息，混着窗外被露水洗过的空气。

> 旅行教会我的，是如何在别处，也能为自己冲一杯熟悉的安稳。

## 靠窗的位子

我喜欢挑靠窗的位子坐下。看晨跑的人、推车的小贩、抱着面包匆匆走过的上班族，城市像一帧帧缓缓显影的胶片，在我面前展开它最朴素的一面。

热咖啡端上来，杯壁烫手。我捧着它，什么也不急着做，只是看光线一点点爬上对面的墙。

## 一座城的清晨

后来我才明白，认识一座城，不必去赶那些著名的景点。只要在清晨坐进一家咖啡店，听它如何醒来，便已读懂了它大半的脾气与温柔。

愿每一段旅途里，都有这样一个清晨，和一杯刚刚好的咖啡。
