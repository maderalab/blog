# AI Agent 入门

AI Agent 是一个能够**感知环境、做出决策并采取行动**来完成目标的系统。与一次性问答不同，Agent 会在一个循环中持续工作，直到任务完成。

## 核心循环

一个最小的 Agent 通常重复以下四步：

1. **观察（Observe）**——读取当前状态与上一步的结果
2. **思考（Think）**——基于目标规划下一步
3. **行动（Act）**——调用工具或产生输出
4. **反馈（Reflect）**——根据结果调整计划

## 关键组件

| 组件 | 作用 |
| --- | --- |
| 模型 | 负责推理与决策 |
| 工具 | 让 Agent 与外部世界交互 |
| 记忆 | 保存上下文与历史 |
| 控制循环 | 串联以上一切 |

## 一段示意代码

```python
while not task.done:
    obs = env.observe()
    action = agent.decide(obs)
    env.act(action)
```

> Agent 的强大之处不在于单步有多聪明，而在于能把许多小步骤可靠地串成一条链。
