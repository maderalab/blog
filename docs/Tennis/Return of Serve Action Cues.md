**1. Basic Return**

```text
Ready position
Split step
Short unit turn
Contact in front
Block or drive
Recover
```

中文要领：
- **准备姿势低**：重心压低，拍子在身体前方，双脚保持弹性。
- **分腿垫步**：对手触球瞬间 split step，马上判断方向。
- **短转肩**：接发球时间少，引拍要小，先转肩带拍。
- **身前触球**：尽量在身体前方挡住球，不要等球顶到身上。
- **挡或打**：快发球用挡，慢二发可以主动打。
- **快速还原**：接完马上回到下一拍准备。

感觉：**动作短，拍面稳，先把球接深。**

**2. Against Fast Serve**

```text
Compact backswing
Firm racket face
Use server's pace
Block deep
Stay balanced
```

中文要领：
- **引拍更短**，甚至只转肩不拉拍。
- **拍面稳定**，手腕固定但不要僵硬。
- **借力回球**，不要硬抡。
- **目标打深**，优先回到中路或大斜线。
- **身体稳定**，不要被球速带歪。

感觉：**借力挡深。**

**3. Against Second Serve**

```text
Step in
Take it early
Drive through
Add spin
Recover forward
```

中文要领：
- **上步进场**，不要站太后等球掉。
- **抢上升期或高点**，压缩对手时间。
- **向前打穿**，用身体进入球。
- **加一点上旋**，保证安全下压。
- **接完准备进攻下一拍**。

感觉：**主动压上去打。**

**4. Chip / Slice Return**

```text
Turn shoulders
Racket head high
Step in
Block-slice through
Keep it low
```

中文要领：
- **转肩带拍**，动作小。
- **拍头高，拍面略开**。
- **上步迎球**，用身体向前挡削。
- **向前下方切送**，不要只往下砍。
- **回球低而深**，让对手不好进攻。

感觉：**挡削进去，低深为主。**

**Common Rules**

```text
Split on server contact
Short backswing
Contact in front
Stable racket face
Return deep first
Recover fast
```

中文要领：
- 对手击球瞬间分腿垫步。
- 引拍要短。
- 身前触球。
- 拍面稳定。
- 先求深度，再求角度。
- 接完立刻还原。

**Target Priority**

```text
1. Deep middle
2. Deep crosscourt
3. Attack weak second serve
```

中文：

**先深中路，再深斜线，弱二发再进攻。**

**Master Cue**

```text
Split → turn short → contact in front → return deep → recover
```

中文：

**垫步 → 短转肩 → 身前触球 → 回深 → 还原。**
