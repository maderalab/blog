# 网球入门第一课

网球是一项讲究**节奏、脚步与专注**的运动。第一节课不需要学会所有技术，只要建立起对球和球拍的基本感觉。

## 装备清单

- 一支适合手型的球拍
- 一双有侧向支撑的网球鞋
- 几颗练习用球
- 一瓶水

## 三种基本击球

1. **正手（Forehand）**——最常用、最自然的击球
2. **反手（Backhand）**——可单手也可双手
3. **发球（Serve）**——每一分的开始
